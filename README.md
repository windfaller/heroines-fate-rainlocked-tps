# 群芳天命錄：雨鎖殘界

3D 第三人稱動作垂直切片。操作凜踏入雨鎖山門，擊敗雨蝕武者，解救緋緒並護送下山。

**遊玩：** [https://windfaller.github.io/heroines-fate-rainlocked-tps/](https://windfaller.github.io/heroines-fate-rainlocked-tps/)

場景：雨鎖山門（Rainbound Shrine）

## 切片角色

| 角色 | 身分 |
| --- | --- |
| 凜 | 可操作主角 |
| 緋緒 | 需解救並護送的同伴 |
| 雨蝕武者 | 兩階段首領 |
| 澄夜 | 燈守／據點 NPC |

## 操作

| 按鍵 | 動作 |
| --- | --- |
| WASD | 移動（鏡頭相對） |
| 滑鼠 | 視角（點擊畫布後鎖定指標） |
| J / 滑鼠左鍵 | 近戰（凜月刃連段） |
| L / 滑鼠右鍵 | 精準射擊 |
| Shift | 閃避（無敵幀） |
| Q / R / F | 控場 / 轉位 / 奧義 |
| E | 互動（斬束縛、點燈） |
| Tab | 鎖定目標 |
| Esc | 暫停 |

目標鏈：進入山門 → 會見澄夜 → 清石階、過斷橋、淨化洗心池、守命燈 → 擊敗雨蝕武者 → 斬斷束縛解救緋緒 → 護送回據點點亮主燈。
